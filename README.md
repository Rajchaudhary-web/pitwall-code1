# AI-Powered F1 Pit Strategy Dashboard

## 🚀 Overview
A real-time dashboard that analyzes Formula 1 race data and provides insights for pit stop strategy using live telemetry, weather, and performance data.

## ⚙️ Tech Stack
- React + TypeScript
- Vite
- Tailwind CSS
- OpenF1 API

## 📊 Features
- Live race data visualization
- Driver performance tracking
- Tire stint analysis
- Weather insights
- Fallback demo data support

## ▶️ Run Locally
```bash
npm install
npm run dev
